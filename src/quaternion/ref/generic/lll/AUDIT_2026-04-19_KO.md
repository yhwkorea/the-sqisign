# MLLL 모듈 감사 보고서 (2026-04-19)

4개 에이전트 병렬로 MLLL 관련 5개 소스를 전수 감사하고, 발견된 이슈를 우선순위별로 픽스했다.

## 감사 범위

| 모듈 | 파일 | 줄 수 |
|---|---|---|
| A | `mlll.c` (Cohen 정수 GSO) | 565 |
| B | `mlll_gram.c` (Gram/L2 래퍼) + `l2.c` (NS09 L²) | 403 + 190 |
| C | `mlll_tests.c` (테스트) | 780 |
| D | `mlll_benchmark.c` (벤치) | 439 |

## 적용된 픽스

### C1 — `track_intermediate` 누락 5곳 추가 (`mlll.c`)

Lemma 3 bound (`≤ max ‖a_i‖²`) 검증에 쓰이는 `track_intermediate` 호출이 **5군데 빠져 있었음**. 벤치가 실제 최대 비트사이즈를 **과소평가**하고 있었다는 뜻.

| 위치 | 추적 대상 | 누락 이유 |
|---|---|---|
| L244 | `tmp1 = t * Λ[l-1][j]` | 곱셈 결과가 감산 전에 사라짐 |
| L250 | `tmp1 = t * d[l]` | 동일 |
| L289 | `lam_sq = Λ[m-1][m-2]²` | 제곱 결과가 add 이후만 추적됨 |
| L342 | `tmp_a = Λ·lam + Λ·d` | 분자가 나눗셈 전에 사라짐 |
| L349 | `tmp_a = Λ·d - Λ·lam` | 동일 |

**재측정 결과 (L1, 10k trials)**:

| 경로 | Before | After | Δ |
|---|---|---|---|
| MLLL (Cohen) max | 3028 | **3543** | **+515 bits** |
| GRAM vec max | 258 | 259 | +1 |
| GRAM Gram max | 516 | 518 | +2 |

→ Cohen path에 515비트짜리 추적 구멍이 실재했음. GRAM 경로는 거의 다 추적돼 있어 변동 미미. **B\*_{1,3,5} typedef 결정엔 영향 없음** (GRAM 기반이므로).

### M1 — Dead code 제거 (`mlll.c:297-300`)

Lovász 테스트 RHS 계산에서 `rhs = 2·d²`, `tmp1 = 4·d²`로 잘못 나간 3줄이 즉시 버려지고 재계산됨. 3줄 삭제.

### M2 — `mlll_internals.h:113` 파라미터 `N` → `norm_N`

Header 파라미터 이름이 `N`이어서 `mlll_gram.c`의 `#define N 16` 매크로와 잠복 충돌 가능성. 현재 include 순서(header → `#define`)로 세이프하나, 역전되면 폭발. 이름 변경으로 근본 해결.

### C2 — `mlll_benchmark.c:281` 메모리 누수

생성 실패 시 `return 1` → 힙 할당된 `lats1/2/norms1/2` 누수. `goto done`으로 경로 통일, `ret_code` 도입.

### C3 — `--mode` 플래그 무음 수락

`--mode=alg33` 같은 오타가 alg2 경로로 조용히 fallback 돼 잘못된 측정을 생산. `--mode`는 alg2/alg3만 허용, 그 외는 에러로 종료. `--iterations`도 양수 체크 추가. malloc 반환값 null 체크 추가.

### M5 — 테스트 커버리지 4건 추가 (`mlll_tests.c`)

기존 8개에 더해:

- `quat_test_mlll_all_zero_generators` — g=4, 전부 0 → rank 0
- `quat_test_mlll_single_generator` — g=1, 비자명 → rank 1, basis col 0 일치
- `quat_test_mlll_two_generators_dependent` — b2 = 2·b1 → rank 1
- `quat_test_mlll_rank_deficient` — g=8, rank 2 sublattice(e1–e2 평면) → rank 2, col 2/3 zero

**전체 12/12 테스트 통과 확인**.

### M4 — Gram 이상성 trials 5 → 25 (`mlll_tests.c`)

`quat_test_lideal_create_gram_equivalence`의 무작위 trial 수가 5였음 (약 2⁻⁵ 신뢰도). 127-bit 이상 크립토 스케일엔 부족하므로 25로 상향.

### M3 — L² 무한루프 가드 (`l2.c` + `mlll_gram.c`)

dpe 정밀도 손실 시 내·외부 루프가 이론상 무한루프 가능. 런타임 가드 추가:

| 루프 | cap | 동작 |
|---|---|---|
| `l2.c` outer (`kappa<4`) | 10000 | `fprintf+abort` |
| `l2.c` 내부 size-reduce | 64 | `fprintf+abort` |
| `mlll_gram.c` outer | 100000 | `fprintf+abort` |
| `mlll_gram.c` 내부 size-reduce | 64 | `fprintf+abort` |

`assert`가 아닌 런타임 체크로 둔 이유는 `NDEBUG` 빌드에서도 활성화되어야 하기 때문.

## 감사 결과 중 **픽스하지 않은 항목**

- **`mlll.c:234` 자기파괴적 인자(`ibz_div_floor(&t, &tmp1, &tmp1, &tmp2)`)** — 의도된 설계 (tmp1이 분자이자 잔여 출력), 유지. 단순 주석 추가는 보류.
- **`mlll_benchmark.c:287` Alg3 헤더 라벨 off-by-one** — 코스메틱, 보류.
- **B 에이전트 false alarm (`mlll_gram.c:309-311 lat_res`)** — 실제는 `red1/red2`, 정상 코드. 무시.

## 감사하면서 확인된 내용 (변경 없음)

- **메모리 누수 없음**: `mlll.c`, `mlll_gram.c`, `mlll_tests.c` 모두 init/finalize 대응 완전.
- **래퍼 구조 OK**: `quat_lattice_mul_mlll_gram` / `_add_mlll_gram` / `_lideal_create_mlll_gram` 모두 HNF 대응본(`quat_lattice_mul`, `_add`, `quat_lideal_create`)과 구조 매치.
- **Calibration OK**: 벤치 출력이 `project_sqisign_mlll.md`의 측정값 258/516, 389/780, 512/1025와 정확히 대응.
- **논문 대응 OK**: `mlll.c` ↔ `03Ideal.tex:13-55` line-by-line 매치 (Cohen 정수형 Lovász는 의도된 변형).

## 논문이 정량화한 비트 감소 (03Ideal.tex / 04Sampling.tex)

논문은 "총 X bits 줄었다" 집계표는 없고, Lemma 점근 bound 비교만 제시:

- **Alg 2 (CompactIdealMultiplication)**: state-of-the-art KLKL25 `O(nrd(I₁I₂)^4)` → 이 논문 `O(nrd(I₁I₂))`. **정확히 1/4 비트** (계수 4 → 1). L1에선 약 **1500+ bits 절감**.
- **Alg 3 (RandomIdealGivenPrimeNorm, Lemma sampling-bound)**: 최대 정수 크기 `< 4N²` → `2·log N + 2` bits. state-of-the-art 비교 미명시.
